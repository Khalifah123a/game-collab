# Platformer 2D Asset Pack for Unity

Paket aset yang dapat langsung dimasukkan ke proyek Unity 2022.3 LTS atau versi lebih baru.

## Isi paket

- 13 frame karakter lengkap yang terlihat pada gambar sumber
- 4 layer background/parallax
- 13 terrain, hazard, dan prop
- 12 ikon item
- Character sheet transparan
- Gambar gameplay dan Unity Editor sebagai referensi
- Unity Editor tools untuk import setting, pembuatan animasi, dan demo scene

Total: **42 sprite individual**.

## Import menggunakan Unity Package

1. Buka proyek Unity.
2. Pilih `Assets > Import Package > Custom Package...`.
3. Pilih `Platformer2DAssetPack.unitypackage`.
4. Klik `Import`.
5. Jalankan `Tools > Platformer Asset Pack > Apply Import Settings`.

## Import menggunakan ZIP

1. Ekstrak ZIP.
2. Salin folder `Assets/Platformer2DAssetPack` ke folder `Assets` proyek Unity.
3. Unity akan mengimpor seluruh PNG sebagai Sprite secara otomatis.

## Tools yang tersedia

- `Apply Import Settings`
- `Create Character Animation`
- `Create Demo Scene`

## Catatan sumber

Aset diekstraksi dari satu gambar komposit yang diberikan pengguna. Bagian karakter yang sudah terpotong di sisi paling kiri gambar sumber tidak dapat dipulihkan, sehingga paket hanya memasukkan frame yang terlihat lengkap. Resolusi dan detail mengikuti kualitas gambar sumber.

Hak penggunaan tetap mengikuti hak atas gambar sumber. Gunakan hanya apabila Anda memiliki izin terhadap karya tersebut.
